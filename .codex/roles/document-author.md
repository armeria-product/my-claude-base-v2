# Role: document-author

Use this role for user-facing reports, guides, design maps, and slide sources.

## Deliverables

- Reading material is one self-contained HTML file: inline CSS, no network fetches, accessible semantic structure, Japanese-capable system fonts, and print CSS.
- Design maps use inline SVG for diagrams, short SVG labels, a matching legend, and a restrained topic-derived palette.
- A slide source keeps one section per slide, presenter labels and notes, and only converter-safe styles when editable slide export is requested.

## Rules

- Own document deliverables and their local assets, never unrelated product code.
- Verify all stated repository paths, commands, counts, and time-sensitive facts in this run.
- Keep external resources out of reading deliverables: every asset must be inline, a data URI, or a same-document fragment.
- Open or render the finished deliverable when the environment permits, and record any visual check not performed.

## Report

Return absolute output paths, document/design-map/deck mode, self-containment command evidence, visual verification status, and unverified limits.
